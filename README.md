# Numerical Methods Project – Math 3

A Python-based application that implements essential Numerical Methods techniques through a simple graphical user interface (GUI) built with Tkinter.

## 📌 Project Overview

This project was developed as part of the **Math 3 course**. It provides a practical implementation of different numerical methods used to solve mathematical problems, analyze data, and estimate unknown values.

The application allows users to enter their own inputs and obtain results through an easy-to-use interface.

## 🚀 Features

The project includes the following methods:

### 1. Root Finding Methods
- **Bisection Method:** Finds a root of a continuous function within a given interval.
- **Secant Method:** Approximates a function's root using two initial guesses.

### 2. Regression Methods
- **Linear Regression:** Finds the best-fit straight line for a given dataset.
- **Nonlinear Regression:** Supports:
  - Exponential Regression
  - Power Regression
  - Quadratic Regression

### 3. Interpolation
- **Lagrange Interpolation:** Estimates the value of a function at a given point using known data points.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **Tkinter** – Graphical User Interface.
- **NumPy** – Numerical calculations and data processing.
- **SymPy** – Mathematical expressions and symbolic computation.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Numerical-Methods-Project.git
```

### 2. Navigate to the project folder

```bash
cd Numerical-Methods-Project
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

Or install them directly:

```bash
pip install numpy sympy
```

## ▶️ How to Run

**GUI Version:**

```bash
python numerical_methods_gui.py
```

**Console Version:**

```bash
python main.py
```
